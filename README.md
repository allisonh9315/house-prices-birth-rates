# House Prices and Birth Rates Across US Metropolitan Areas

Stata 17 code for my ECON 422 (Econometrics) research project at the University of Maryland.

The do-file builds a dataset of 256 US metro areas from 2023 American Community Survey tables and IPUMS USA microdata, then estimates how median home values relate to the general fertility rate.

**Data sources:** U.S. Census Bureau ACS 1-Year Tables B13016, B15001, B19013, B23025, B25077; IPUMS USA (Ruggles et al. 2025). Data files are not included; see the comments in the code for how to download them.
